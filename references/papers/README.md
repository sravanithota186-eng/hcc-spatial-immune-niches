# Paper PDFs

Only commit PDFs you are **allowed to redistribute** (open-access / CC-BY). Name them `OA_<firstauthor>_<year>_<journal>.pdf`.
Everything else stays on your own machine (the `.gitignore` blocks non-`OA_` PDFs) and is tracked in `../references.md`.

| Paper | Open access? | Suggested file name |
|---|---|---|
| Zhang et al. 2023, Genome Med | Yes (CC BY 4.0) | `OA_Zhang_2023_GenomeMed.pdf` |
| Magen et al. 2023, Nat Med | Author manuscript on PMC (PMC11027932) | `OA_Magen_2023_NatMed.pdf` (check PMC licence) |
| Cappuyns et al. 2023, Nat Commun | Yes (Nature Communications is OA) | `OA_Cappuyns_2023_NatCommun.pdf` |
| Bai et al. 2022, Front Immunol | Yes (Frontiers) | `OA_Bai_2022_FrontImmunol.pdf` |
| Others | Check each journal's licence | — |
